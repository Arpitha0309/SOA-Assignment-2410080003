# Create and Configure an Amazon RDS MySQL Database

## Objective
To create and configure an Amazon RDS MySQL database, establish a connection using MySQL Command Line Client, and perform basic SQL operations.

## Technologies Used
- Amazon Web Services (AWS)
- Amazon RDS
- MySQL
- Windows PowerShell
- SQL

## Experiment Steps
1. Create an Amazon RDS MySQL database instance.
2. Configure database identifier, username and password.
3. Configure instance class and storage.
4. Configure the database within a VPC.
5. Configure security group access on port 3306.
6. Connect to RDS using MySQL Command Line Client.
7. Create StudentDB database.
8. Create Student table.
9. Insert five student records.
10. Retrieve records using SELECT query.

## Database Details
- Database: StudentDB
- Table: Student
- Columns: Student_ID, Student_Name, Department, Email
- Records inserted: 5

## Output
Successfully created the StudentDB database, created the Student table, inserted five records and retrieved them using the SELECT statement.
